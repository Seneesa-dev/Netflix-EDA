# Netflix Movies & TV Shows – EDA

## Objective
Perform exploratory data analysis on Netflix content to identify trends in content type, genres, countries, and yearly growth.

## Dataset
my_netflix_dataset.csv

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Netflix has more movies than TV shows
- Content additions increased significantly after 2016
- USA dominates content production
- Drama and Comedy are the most common genres
